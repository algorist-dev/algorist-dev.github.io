ぴったり証明写真（以下「本アプリ」）

まとめ：本アプリは、写真や個人の情報を集めません。写真の処理はすべてお使いの iPhone の中で行い、開発者や第三者に送ることはありません。顔を測った値（顔のデータ）は保存せず、写真を仕上げ終えると消えます。

1. 集める情報

本アプリは、利用者の個人の情報・写真・利用状況を開発者のもとへ集めません。サーバー・アカウント登録・広告・アクセス解析・トラッキングの仕組みはありません。

2. 写真の扱い

  • 撮影した写真や選んだ写真は、iPhone の中だけで顔の位置を測り、切り取ります（Apple の Vision フレームワークを端末の中で使います）。
  • 仕上がった写真は、本アプリの中（端末内）に保存します。この保存先は iCloud やパソコンへのバックアップから外しています。
  • 保存した写真は、ホームの一覧から削除できます。本アプリを削除すると、すべて消えます。
  • 利用者が「写真」への保存や共有を選んだときだけ、その画像が「写真」アプリや共有先へ渡ります。共有先での扱いは、それぞれのサービスの方針に従います。

3. 顔のデータ（Face data）

本アプリは、証明写真を規格の大きさに切り取るために、Apple の Vision フレームワークを使って、iPhone の中で写真の中の顔を測ります。

  • 測るもの：顔の枠（位置と大きさ）、顔の輪郭の点（あごの位置を知るため）、顔の傾きと向き、人と背景の境目（頭のてっぺんと背景を調べるため）。
  • 使い道：写真を切り取る位置を決めることと、規格に合っているか（顔の大きさ・傾き・背景）を確かめることだけに使います。人を見分ける（顔認証・本人確認）ことには使いません。
  • 保存：測った値は、写真を仕上げている間（撮る・調整・保存の画面）だけ iPhone のメモリーの中に置き、ホームの画面に戻るかアプリを終えると消えます。ファイルにも端末の外にも保存しません。
  • 送信・第三者への提供：顔のデータを開発者や第三者に送ることはありません。サーバー・広告・アクセス解析・AI のサービスは使っていません。
  • 保存期間と削除：顔のデータは保存しないため、保存期間はありません。仕上がった写真（画像そのもの）は「2. 写真の扱い」のとおり端末の中だけに保存し、ホームの一覧から、または本アプリを削除することで消せます。

Face data (English)

To crop ID photos to the official size, the app uses Apple's Vision framework on the device to measure the face in the photo.

  • What is measured: the face bounding box (position and size), face contour points (to find the chin), face tilt and angle, and a person/background mask (to find the top of the head and check the background).
  • Use: only to decide where to crop the photo and to check that it meets the size rules (face size, tilt and background). It is never used to identify or authenticate a person.
  • Storage: these measurements exist only in the device's memory while the user is finishing the photo (the capture, adjustment and save screens), and are discarded when the user returns to the home screen or the app quits. They are never written to a file and never leave the device.
  • Sharing: face data is never sent to the developer or to any third party. The app has no server, advertising, analytics or AI services.
  • Retention and deletion: face data is not stored, so there is no retention period. The finished photo itself is stored only on the device as described in Section 2, and the user can delete it from the list on the home screen or by deleting the app.

4. 使う権限

  • カメラ：証明写真を撮るために使います。
  • 写真への追加：印刷用の画像を「写真」に保存するために使います。写真を読み取る権限は求めません（写真を選ぶときは、iOS の写真の選択画面を使います）。

5. アプリ内の購入

購入の手続きは Apple の App Store が行います。開発者はお支払いの情報（カード番号など）を受け取りません。購入の状態の確認には Apple の StoreKit を使います。Apple による情報の扱いは、Apple のプライバシーポリシーをご覧ください。

6. 第三者への提供

集める情報がないため、第三者へ提供することはありません。
